# 论可计算数及其在判定问题中的应用

**A. M. 图灵**

“可计算”数可以简短地描述为这样一些实数：它们以小数形式表示时，可以由有限手段计算出来。虽然本文的主题表面上是可计算数，但定义并研究整变量的可计算函数、实变量或可计算变量的可计算函数、可计算谓词等等，几乎同样容易。然而，其中所涉及的根本问题在每种情形下都是相同的；我选择可计算数作明确处理，是因为它所需的技术最为轻便。我希望不久后能说明可计算数、函数等等之间的关系。这将包括以可计算数为术语来表达的实变函数理论的发展。按照我的定义，如果一个数的小数可以由一台机器写出来，它就是可计算的。

在第 9、10 节中，我给出若干论证，意在表明可计算数包括所有可以自然地被看作可计算的数。尤其我会证明，某些大类数都是可计算的。它们包括例如所有代数数的实部、贝塞尔函数零点的实部、$\pi$、$e$ 等。然而，可计算数并不包括所有可定义数；文中给出一个可定义但不可计算的数的例子。

尽管可计算数的类如此之大，并且在许多方面类似于实数的类，它却是可以枚举的。在第 8 节中，我考察了某些似乎要证明相反结论的论证。通过正确应用其中一个论证，可以得到与哥德尔 [1] 的结果表面上相似的结论。这些结果具有重要应用。特别地，文中证明（第 11 节）希尔伯特的判定问题不可能有解。

在最近的一篇论文中，阿隆佐·丘奇 [2] 引入了“有效可计算性”的概念，它与我的“可计算性”等价，但定义方式非常不同。丘奇也就判定问题得出了类似结论 [3]。“可计算性”与“有效可计算性”之间等价性的证明，在本文附录中作了概述。

## 1. 计算机器

我们说过，可计算数是那些其小数可以由有限手段计算出来的数。这需要更明确的定义。在到达第 9 节之前，我不会真正试图证明所给出的定义的合理性。目前我只想说，其理由在于人的记忆必然是有限的。

我们可以把正在计算一个实数的人比作一台机器，这台机器只能处于有限数量的条件 $q_1,q_2,\ldots,q_R$ 之中，这些条件称为“m-构型”。机器配有一条“纸带”（纸的对应物）穿过其中，纸带被划分为若干部分，称为“方格”，每个方格可以承载一个“符号”。在任一时刻，恰有一个方格——比如第 $r$ 个方格——承载着“处于机器中”的符号 $S(r)$。我们可以称这个方格为“被扫描方格”。被扫描方格上的符号可以称为“被扫描符号”。可以说，“被扫描符号”是机器“直接知晓”的唯一符号。然而，通过改变其 m-构型，机器能够有效地记住它先前“看见”（扫描）过的某些符号。机器在任一时刻可能采取的行为，由 m-构型 $q_n$ 和被扫描符号 $S(r)$ 决定。这一对 $q_n,S(r)$ 将称为“构型”：因此，构型决定了机器的可能行为。在扫描方格为空白（即不承载符号）的某些构型中，机器会在被扫描方格上写下一个新符号；在另一些构型中，它会擦去被扫描符号。机器也可以改变正在被扫描的方格，但只能把它向右或向左移动一格。除了这些操作之外，m-构型也可以改变。写下的某些符号将构成数字序列，即正在计算的实数的小数；其余符号只是“帮助记忆”的草稿。只有这些草稿才可能被擦除。

我的主张是，这些操作包括了计算一个数时所使用的全部操作。等读者熟悉了机器理论之后，为这一主张辩护会更容易。因此，在下一节中，我继续展开这一理论，并假定“机器”“纸带”“扫描”等术语的含义已被理解。

## 2. 定义

### 自动机

==如果机器（在第 1 节的意义上）在每一阶段的运动完全由构型决定，我们就称它为“自动机”==（即 a-machine）。出于某些目的，我们可能会使用其运动仅部分由构型决定的机器（选择机或 c-machine，因此第 1 节中使用了“可能”一词）。当这样的机器到达某个歧义构型时，除非外部操作者作出某种任意选择，否则它无法继续。如果我们用机器处理公理系统，就会是这种情况。本文只处理自动机，因此常省略前缀 a-。

### 计算机器

如果一台 a-machine 打印两类符号，其中第一类（称为数字）完全由 $0$ 和 $1$ 组成（其余称为第二类符号），则称该机器为计算机器。如果给机器一条空白纸带并从正确的初始 m-构型开始启动，那么它打印出的第一类符号的子序列，称为该机器计算的序列。把这个序列前面加上小数点所得二进制小数所表示的实数，称为该机器计算的数。

在机器运动的任一阶段，被扫描方格的编号、纸带上所有符号的完整序列以及 m-构型，将被称为描述该阶段的**完全构型**。相继两个完全构型之间机器和纸带的变化，称为机器的**移动**。

### 循环机与无循环机

如果一台计算机器写下的第一类符号从不超过有限个，则称它是**循环的**；否则称它是**无循环的**。

如果一台机器到达一个没有可能移动的构型，或者它继续运动并可能打印第二类符号，但不能再打印任何第一类符号，那么它就是循环的。“循环”一词的意义将在第 8 节解释。

### 可计算序列与可计算数

如果一个序列可以由无循环机器计算，则称它是**可计算的**。如果一个数由无循环机器计算的数相差一个整数，则称它是可计算的。

为避免混淆，我们将更常说可计算序列，而不是可计算数。

## 3. 计算机器的例子

**I.** 可以构造一台机器来计算序列 $010101\ldots$。该机器具有四个 m-构型“b”“c”“f”“e”，并能打印“0”和“1”。机器的行为由下表描述，其中“R”表示“机器移动，使其扫描先前所扫描方格的右边紧邻方格”；“L”同理。“E”表示被扫描符号被“擦除”，“P”表示“打印”。该表（以及以下所有同类表格）应理解为：对于前两列所描述的构型，依次执行第三列中的操作，然后机器转入最后一列所描述的 m-构型。当第二列留空时，应理解为第三、四列的行为适用于任何符号，也适用于没有符号的情形。机器从 m-构型 b 和空白纸带开始。

| m-构型 | 符号 | 操作 | 终态 m-构型 |
| --- | --- | --- | --- |
| b | 空白 | $P0,\,R$ | c |
| c | 空白 | $R$ | e |
| e | 空白 | $P1,\,R$ | f |
| f | 空白 | $R$ | b |

如果（与第 1 节的描述相反）我们允许字母 L、R 在操作列中出现不止一次，就可以显著简化该表。

| m-构型 | 符号 | 操作 | 终态 m-构型 |
| --- | --- | --- | --- |
| b | 空白 | $P0$ | b |
| b | 0 | $R,\,R,\,P1$ | b |
| b | 1 | $R,\,R,\,P0$ | b |

**II.** 作为稍微困难一点的例子，我们可以构造一台机器来计算序列 $001011011101111011111\ldots$。该机器应能处于五个 m-构型，即“o”“q”“p”“f”“b”，并能打印“ə”“x”“0”“1”。纸带上的前三个符号将是“əə0”；其余数字跟在隔一个的方格上。在中间方格上，我们从不打印除“x”以外的任何东西。这些字母为我们“占位”，用完后即被擦除。我们还安排：在隔格上的数字序列中不出现空白。

| m-构型 | 符号 | 操作 | 终态 m-构型 |
| --- | --- | --- | --- |
| b | 空白 | $Pə,\,R,\,Pə,\,R,\,P0,\,R,\,R,\,P0,\,L,\,L$ | o |
| o | 1 | $R,\,Px,\,L,\,L,\,L$ | o |
| o | 0 | $R,\,Px,\,L,\,L,\,L$ | o |
| q | 任意（0 或 1） | $R,\,R$ | q |
| q | 空白 | $P1,\,L$ | p |
| p | x | $E,\,R$ | q |
| p | ə | $R$ | f |
| p | 空白 | $L,\,L$ | q |
| f | 任意 | $R,\,R$ | f |
| f | 空白 | $P0,\,L,\,L$ | o |

为说明这台机器的工作，下面给出最初几个完全构型。这些完全构型通过写下纸带上的符号序列来描述，m-构型写在被扫描符号之下。相继的完全构型用冒号分隔。

```text
: ə ə 0   0 : ə ə 0   0 : ə ə 0   0 : ə ə 0   0   1 : ə ə 0   0   1 :
  b          o             q             q             q             p

  ə ə 0   0   1 : ə ə 0   0   1 : ə ə 0   0   1 : ə ə 0   0   1 :
                p             p             f             f

  ə ə 0   0   1 : ə ə 0   0   1 : ə ə 0   0   1   0 : ə ə 0   0   1   x   0 : ...
                f             f             o                         o
```

该表也可写成如下形式：

```text
b : ə ə o 0   0 : ə ə q 0   0 : …                                      (C)
```

其中在被扫描符号左侧留出一个空格，并把 m-构型写在这个空格中。这种形式较难理解，但以后在理论讨论中我们会用到它。

只在隔格上写数字的约定非常有用：我将始终采用它。我把其中一列隔格称为 F-方格，另一列称为 E-方格。E-方格上的符号容易被擦除。F-方格上的符号构成一个连续序列；在到达末端之前没有空白。每对 F-方格之间不必有多于一个 E-方格：对更多 E-方格的表面需要，可以通过在 E-方格上可打印的符号种类足够丰富来满足。如果符号 $\beta$ 在 F-方格 $S$ 上，符号 $\alpha$ 在 $S$ 右边紧邻的 E-方格上，则称 $\beta$ 与 $S$ 被 $\alpha$ **标记**。打印这个 $\alpha$ 的过程称为用 $\alpha$ 标记 $\beta$（或 $S$）。

## 4. 简写表

有若干过程几乎被所有机器使用，并且在某些机器中，这些过程被用于许多不同场合。这些过程包括抄录符号序列、比较序列、擦去某种给定形式的所有符号等。涉及这类过程时，我们可以借助“骨架表”大幅简写 m-构型表。骨架表中出现大写哥特字母 [4] 和小写希腊字母。它们具有“变量”的性质。如果把每个大写哥特字母到处都替换为一个 m-构型，把每个小写希腊字母替换为一个符号，就得到某个 m-构型的表。

骨架表只应被视为简写：它们并非本质所在。只要读者理解如何由骨架表得到完整表，就不必为此给出任何精确定义。

让我们考虑一个例子：

| m-构型 | 符号 | 行为 | 终态 m-构型 |
| --- | --- | --- | --- |
| $f(\mathfrak C,\mathfrak B,\alpha)$ | ə | $L$ | $f_1(\mathfrak C,\mathfrak B,\alpha)$ |
| $f(\mathfrak C,\mathfrak B,\alpha)$ | 非 ə | $L$ | $f(\mathfrak C,\mathfrak B,\alpha)$ |
| $f_1(\mathfrak C,\mathfrak B,\alpha)$ | $\alpha$ | — | $\mathfrak C$ |
| $f_1(\mathfrak C,\mathfrak B,\alpha)$ | 非 $\alpha$ | $R$ | $f_1(\mathfrak C,\mathfrak B,\alpha)$ |
| $f_1(\mathfrak C,\mathfrak B,\alpha)$ | 空白 | $R$ | $f_2(\mathfrak C,\mathfrak B,\alpha)$ |
| $f_2(\mathfrak C,\mathfrak B,\alpha)$ | $\alpha$ | — | $\mathfrak C$ |
| $f_2(\mathfrak C,\mathfrak B,\alpha)$ | 非 $\alpha$ | $R$ | $f_1(\mathfrak C,\mathfrak B,\alpha)$ |
| $f_2(\mathfrak C,\mathfrak B,\alpha)$ | 空白 | $R$ | $\mathfrak B$ |

从 m-构型 $f(\mathfrak C,\mathfrak B,\alpha)$ 出发，机器找到最左边的 $\alpha$ 形式符号（“第一个 $\alpha$”），然后 m-构型变为 $\mathfrak C$。若没有 $\alpha$，则 m-构型变为 $\mathfrak B$。

如果把 $\mathfrak C$ 全部替换为 $q$（比如说），把 $\mathfrak B$ 替换为 $r$，把 $\alpha$ 替换为 $x$，我们就得到 m-构型 $f(q,r,x)$ 的完整表。$f$ 称为“m-构型函数”或“m-函数”。

可代入 m-函数的表达式只有机器的 m-构型和符号。这些必须多少明确地列举出来：它们可以包含诸如 $p(e,x)$ 这样的表达式；事实上，只要使用了任何 m-函数，它们就必须包含这类表达式。如果我们不坚持这种明确列举，而只是说机器具有某些 m-构型（已列举）以及通过在某些 m-函数中代入 m-构型而可获得的所有 m-构型，那么通常会得到无穷多个 m-构型。例如，我们可以说机器具有 m-构型 $q$ 以及通过在 $p(\mathfrak C)$ 中把 m-构型代入 $\mathfrak C$ 而获得的所有 m-构型。于是它将具有 $q$、$p(q)$、$p(p(q))$、$p(p(p(q))),\ldots$ 作为 m-构型。

我们的解释规则于是如下。我们被给予机器的 m-构型名称，其中大多数以 m-函数的形式表达。我们也被给予骨架表。我们所需要的只是机器 m-构型的完整表。它通过反复代入骨架表而获得。

### 更多例子

（在解释中，符号“$\to$”用来表示“机器进入 m-构型……”）

```text
e(𝔈, 𝔅, α)      f(e₁(𝔈, 𝔅, α), 𝔅, α)
e₁(𝔈, 𝔅, α)     E                         𝔈
e(𝔅, α)         e(e(𝔅, α), 𝔅, α)
```

从 $e(\mathfrak C,\mathfrak B,\alpha)$ 出发，第一个 $\alpha$ 被擦除并 $\to\mathfrak C$。若没有 $\alpha$ 则 $\to\mathfrak B$。

从 $e(\mathfrak B,\alpha)$ 出发，所有字母 $\alpha$ 都被擦除并 $\to\mathfrak B$。

最后一个例子看起来比大多数例子更难解释。假设某台机器的 m-构型列表中出现 $e(b,x)$（设为 $q$）。表为：

```text
e(b, x)      e(e(b, x), b, x)
或
q            e(q, b, x)
```

更详细地说：

```text
q                 e(q, b, x)
e(q, b, x)        f(e₁(q, b, x), b, x)
e₁(q, b, x)       E                         q
```

在此我们可以把 $e_1(q,b,x)$ 替换为 $q'$，然后给出 $f$ 的表（作适当代入），最终得到一个不出现 m-函数的表。

```text
pe(𝔈, β)       f(pe₁(𝔈, β), 𝔈, ə)
pe₁(𝔈, β) { 任意   R, R     pe₁(𝔈, β)
             空白   Pβ       𝔈
ı(𝔈)          L                𝔈
r(𝔈)          R                𝔈
f′(𝔈, 𝔅, α)   f(ı(𝔈), 𝔅, α)
f″(𝔈, 𝔅, α)   f(r(𝔈), 𝔅, α)
c(𝔈, 𝔅, α)    f′(c₁(𝔈), 𝔅, α)
c₁(𝔈) { β                     pe(𝔈, β)
```

从 $pe(\mathfrak C,\beta)$ 出发，机器在符号序列的末尾打印 $\beta$ 并 $\to\mathfrak C$。从 $f'(\mathfrak C,\mathfrak B,\alpha)$ 出发，它的行为与 $f(\mathfrak C,\mathfrak B,\alpha)$ 相同，但在 $\to\mathfrak C$ 之前向左移动。$c(\mathfrak C,\mathfrak B,\alpha)$ 在末尾写下第一个被 $\alpha$ 标记的符号并 $\to\mathfrak C$。

最后一行代表通过把 $\beta$ 替换为相关机器纸带上可能出现的任何符号而获得的所有行的总体。

```text
ce(𝔈, 𝔅, α)    c(e(𝔈, 𝔅, α), 𝔅, α)
ce(𝔅, α)       ce(ce(𝔅, α), 𝔅, α)
```

机器依次在末尾抄下所有被 $\alpha$ 标记的符号，并擦去字母 $\alpha$；$\to\mathfrak B$。

```text
re(𝔈, 𝔅, α, β)      E, Pβ
re₁(𝔈, 𝔅, α, β)     f(re₁(𝔈, 𝔅, α, β), 𝔅, α)
                      𝔈
                      𝔅
re(𝔅, α, β)          re(re(𝔅, α, β), 𝔅, α, β)
```

机器把第一个 $\alpha$ 替换为 $\beta$ 并 $\to\mathfrak C$；若没有 $\alpha$ 则 $\to\mathfrak B$。$re(\mathfrak B,\alpha,\beta)$ 把所有字母 $\alpha$ 替换为 $\beta$；$\to\mathfrak B$。

```text
cr(𝔈, 𝔅, α)     c(re(𝔈, 𝔅, α, α), 𝔅, α)
cr(𝔅, α)        cr(cr(𝔅, α), re(𝔅, α, α), α)
```

$cr(\mathfrak B,\alpha)$ 与 $ce(\mathfrak B,\alpha)$ 的区别仅在于字母 $\alpha$ 不被擦除。当纸带上没有字母“a”时，采用 m-构型 $cr(\mathfrak B,\alpha)$。

```text
cp(𝔈, 𝔘, 𝔈, α, β)      f″(cp₁(𝔈₁, 𝔘, β), f(𝔘, 𝔈, β), α)
cp₁(𝔈, 𝔘, β) { γ       f″(cp₂(𝔈, 𝔘, γ), 𝔘, β)
cp₂(𝔈, 𝔘, γ) { γ       𝔈
                 非 γ    𝔘
cpe(𝔈, 𝔘, 𝔈, α, β)      cp(e(e(𝔈, 𝔈, β), 𝔈, α), 𝔘, 𝔈, α, β)
cpe(𝔘, 𝔈, α, β)         cpe(cpe(𝔘, 𝔈, α, β), 𝔘, 𝔈, α, β)
```

第一个被 $\alpha$ 标记的符号与第一个被 $\beta$ 标记的符号被比较。若既无 $\alpha$ 也无 $\beta$，则 $\to\mathfrak E$。若两者都有且符号相同，则 $\to\mathfrak C$；否则 $\to\mathfrak U$。$cpe(\mathfrak C,\mathfrak U,\mathfrak E,\alpha,\beta)$ 与 $cp(\mathfrak C,\mathfrak U,\mathfrak E,\alpha,\beta)$ 的区别在于：在相同的情况下，第一个 $\alpha$ 和 $\beta$ 被擦除。$cpe(\mathfrak U,\mathfrak E,\alpha,\beta)$ 把被 $\alpha$ 标记的符号序列与被 $\beta$ 标记的符号序列比较；若相同则 $\to\mathfrak E$，否则 $\to\mathfrak U$。某些 $\alpha$ 和 $\beta$ 符号会被擦除。

```text
        空白   R       q₁(𝔈)
q₁(𝔈)          q(𝔈, α)
q(𝔈, α)        q(q₁(𝔈, α))
q₁(𝔈, α) { α   L       𝔈
            非 α         q₁(𝔈, α)

ce₂(𝔅, α, β)   ce(ce(𝔅, β), α)
ce₃(𝔅, α, β, γ) ce(ce₂(𝔅, β, γ), α)

        非 ə    L       e(𝔈)
e₁(𝔈) { 任意  R, E, R  e₁(𝔈)
        空白            𝔈
```

$q(\mathfrak C,\alpha)$ 寻找 $\alpha$ 形式的最后一个符号并 $\to\mathfrak C$。$pe_2(\mathfrak C,\alpha,\beta)$ 在末尾打印 $\alpha\beta$。$ce_2(\mathfrak B,\alpha,\beta)$ 在末尾先抄录被 $\alpha$ 标记的符号，再抄录被 $\beta$ 标记的符号，并擦去符号 $\alpha$、$\beta$。$ce_3(\mathfrak B,\alpha,\beta,\gamma)$ 在末尾先抄录被 $\alpha$ 标记的符号，然后是被 $\beta$ 标记的符号，最后是被 $\gamma$ 标记的符号；它擦去符号 $\alpha$、$\beta$、$\gamma$。从 $e(\mathfrak C)$ 出发，所有被标记符号上的标记被擦除并 $\to\mathfrak C$。

## 5. 可计算序列的枚举

一个可计算序列 $\gamma$ 由计算 $\gamma$ 的机器描述决定。因此，序列 $001011011101111\ldots$ 由第 234 页的表决定；事实上，任何可计算序列都能用这样的表来描述。

把这些表放入某种标准形式会很有用。首先，假设表以与第一个表（例如第 233 页上的表 I）相同的形式给出。也就是说，操作列中的条目总是以下形式之一：$E$、$E,R$、$E,L$、$P\alpha$、$P\alpha,R$、$P\alpha,L$、$R$、$L$，或者根本没有条目。通过引入更多 m-构型，总能把表变成这种形式。现在我们给 m-构型编号，称它们为 $q_1,\ldots,q_R$，如第 1 节所示。初始 m-构型总是称为 $q_1$。我们也给符号编号 $S_1,\ldots,S_m$，特别地，空白 $=S_0$，$0=S_1$，$1=S_2$。表的各行现在具有以下形式：

$$
\begin{aligned}
&q_i\; S_j\; PS_k,L\; q_m \qquad (N_1)\\
&q_i\; S_j\; PS_k,R\; q_m \qquad (N_2)\\
&q_i\; S_j\; PS_k\;\; q_m \qquad (N_3)
\end{aligned}
$$

诸如

$$q_j\; S_j\; E,R\; q_m$$

这样的行应写成

$$q_j\; S_j\; PS_0,R\; q_m$$

而诸如

$$q_j\; S_j\; R\; q_m$$

这样的行应写成

$$q_j\; S_j\; PS_j,R\; q_m$$

这样，我们把表的每一行都归约为 $(N_1)$、$(N_2)$、$(N_3)$ 三种形式之一。

从 $(N_1)$ 形式的每一行，我们构成表达式 $q_iS_jS_kLq_m$；从 $(N_2)$ 形式的每一行，我们构成表达式 $q_iS_jS_kRq_m$；从 $(N_3)$ 形式的每一行，我们构成表达式 $q_iS_jS_kNq_m$。

让我们写下由机器的表构成的所有表达式，并用分号分隔。这样我们就得到机器的完整描述。在这个描述中，我们将用字母 “D” 后接重复 $i$ 次的字母 “A” 来替换 $q_i$，用 “D” 后接重复 $j$ 次的字母 “C” 来替换 $S_j$。机器的这一新描述可以称为**标准描述**（S.D.）。它完全由字母 “A”“C”“D”“L”“R”“N” 以及 “;” 组成。

如果最后我们把 “A” 替换为 “1”，“C” 替换为 “2”，“D” 替换为 “3”，“L” 替换为 “4”，“R” 替换为 “5”，“N” 替换为 “6”，“;” 替换为 “7”，我们就得到以阿拉伯数字形式表示的机器描述。这个数字所表示的整数可以称为机器的**描述数**（D.N.）。D.N. 唯一地决定 S.D. 和机器的结构。D.N. 为 $n$ 的机器可记为 $M(n)$。

每个可计算序列至少对应一个描述数，而没有任何一个描述数对应多于一个可计算序列。因此，可计算序列和可计算数是可枚举的。

让我们求第 3 节中机器 I 的一个描述数。当我们重新命名其 m-构型时，它的表变为：

```text
q1 S0 PS1, R q2
q2 S0 PS0, R q3
q3 S0 PS2, R q4
q4 S0 PS0, R q1
```

也可以加入无关的行而得到其他表，例如：

```text
q1 S1 PS1, R q2
```

我们的第一个标准形式为：

```text
q1 S0 S1 R q2; q2 S0 S0 R q3; q3 S0 S2 R q4; q4 S0 S0 R q1;
```

标准描述为：

```text
DADDCRDAA ;DAADDRDAAA ;DAAADDCCRDAAAA ;DAAAADDRDA ;
```

一个描述数为：

```text
31332531173113353111731113322531111731111335317
```

另一个描述数为：

```text
3133253117311335311173111332253111173111133531731323253117
```

作为无循环机器描述数的数，将称为**合格数**。在第 8 节中将证明：不存在判定一个给定数是否合格的一般过程。

## 6. 通用计算机器

==可以发明一台单独的机器，用它来计算任何可计算序列。== 如果这台机器 $U$ 得到一条纸带，纸带开头写着某台计算机器 $M$ 的 S.D.，那么 $U$ 将计算与 $M$ 相同的序列。本节中我概述这台机器的行为；下一节则给出 $U$ 的完整表。

首先假设我们有一台机器 $M'$，它会在 F-方格上写下 $M$ 的相继完全构型。这些完全构型可以用第 235 页上的形式表示，采用第二种描述 (C)，把所有符号放在一行上。或者更好的是，我们可以像第 5 节那样变换这种描述：把每个 m-构型替换为 “D” 后接适当次数重复的 “A”，把每个符号替换为 “D” 后接适当次数重复的 “C”。字母 “A” 和 “C” 的个数应与第 5 节中选择的号码一致，因此特别地，“0” 替换为 “DC”，“1” 替换为 “DCC”，空白替换为 “D”。这些替换应在完全构型按 (C) 方式组合起来之后进行。如果先作替换，就会出现困难：在每个完全构型中，所有空白都得替换为 “D”，于是完全构型就不能表示成有限的符号序列了。

如果在第 3 节机器 II 的描述中把 “o” 替换为 “DAA”，把 “ə” 替换为 “DCCC”，把 “q” 替换为 “DAAA”，则序列 (C) 变为：

```text
DA : DCCCDCCCDAADCDDC : DCCCDCCCDAAADCDDC : …                          (C1)
```

（这是 F-方格上的符号序列。）

不难看出，如果 $M$ 可以构造，那么 $M'$ 也可以构造。$M'$ 的操作方式可以依赖于写在它自身内部（即 $M'$ 内部）某处的 $M$ 的操作规则（即 S.D.）；每一步都可以通过参考这些规则来执行。我们只需把这些规则看作可以被取出并替换成其他规则，就得到了非常接近于通用机器的东西。

还缺少一件事：目前机器 $M'$ 不打印数字。我们可以通过在每两个相继完全构型之间打印在新构型中出现而在旧构型中不出现的数字来纠正这一点。于是 (C1) 变为：

```text
DDA : 0 : 0 : DCCCDCCCDAADCDDC : DCCC. …                                (C2)
```

E-方格是否为必要的“草稿工作”留下足够空间，并不完全显然；但事实确实如此。

诸如 (C1) 中冒号之间的字母序列，可以用作完全构型的标准描述。当字母像第 5 节那样被数字替换时，我们就得到完全构型的数字描述，可以称为它的描述数。

## 8. 对角论证的应用

有人可能认为，证明实数不可枚举的论证也会证明可计算数和可计算序列不可枚举 [5]。例如，可能有人认为可计算数列的极限必定可计算。这显然只有在可计算数列由某条规则定义时才成立。

或者我们可以应用对角论证：“如果可计算序列可枚举，设 $\alpha_n$ 是第 $n$ 个可计算序列，$\varphi_n(m)$ 是 $\alpha_n$ 中第 $m$ 位数字。令 $\beta$ 为以 $1-\varphi_n(n)$ 作为第 $n$ 位数字的序列。由于 $\beta$ 可计算，存在数 $K$ 使得对所有 $n$ 都有 $1-\varphi_n(n)=\varphi_K(n)$。令 $n=K$，得到 $1=2\varphi_K(K)$，即 1 是偶数。这不可能。因此可计算序列不可枚举。”

这一论证的错误在于假设 $\beta$ 可计算。如果我们能用有限手段枚举可计算序列，这一点就会成立；但枚举可计算序列的问题等价于判定一个给定数是否为无循环机器的 D.N. 的问题，而我们没有以有限步数完成这件事的一般过程。事实上，通过正确应用对角论证，我们可以证明不可能存在这样的一般过程。

最简单、最直接的证明是：如果这一一般过程存在，那么就存在一台计算机器 $\beta$。这个证明虽然完全可靠，但缺点在于可能使读者感到“一定有什么地方不对”。我将给出的证明没有这个缺点，并且能让人对“无循环”这一思想的意义有某种洞见。它不依赖于构造 $\beta$，而依赖于构造 $\beta'$，其第 $n$ 位数字是 $\varphi_n(n)$。

让我们假设存在这样的过程；也就是说，我们可以发明一台机器 $D$，当给它任何计算机器 $M$ 的 S.D. 时，它会检验这个 S.D.；如果 $M$ 是循环的，就用符号“u”标记该 S.D.；如果 $M$ 是无循环的，就用“s”标记它。通过把机器 $D$ 和 $U$ 组合起来，我们可以构造一台计算序列 $\beta'$ 的机器 $H$。机器 $D$ 可能需要一条纸带。我们可以假定它使用 F-方格上所有符号之外的 E-方格，并且当它得出结论后，$D$ 所做的所有草稿工作都被擦除。

机器 $H$ 的运动分为若干段。在前 $N-1$ 段中，除其他事情外，整数 $1,2,\ldots,N-1$ 已被写下并由机器 $D$ 检验。其中有一定数量，设为 $R(N-1)$，被发现是无循环机器的 D.N.。在第 $N$ 段中，机器 $D$ 检验数 $N$。如果 $N$ 合格，即它是无循环机器的 D.N.，则 $R(N)=1+R(N-1)$，并计算 D.N. 为 $N$ 的序列的前 $R(N)$ 位数字。该序列的第 $R(N)$ 位数字被写为由 $H$ 计算的序列 $\beta'$ 的数字之一。如果 $N$ 不合格，则 $R(N)=R(N-1)$，机器继续其运动的第 $N+1$ 段。

由 $H$ 的构造可以看出，$H$ 是无循环的。$H$ 运动的每一段都在有限步后结束。因为根据我们对 $D$ 的假设，判定 $N$ 是否合格会在有限步内得出。若 $N$ 不合格，则第 $N$ 段结束。若 $N$ 合格，这意味着 D.N. 为 $N$ 的机器 $M(N)$ 是无循环的，因此它的第 $R(N)$ 位数字可以在有限步内计算出来。当这个数字被计算并写为 $\beta'$ 的第 $R(N)$ 位数字时，第 $N$ 段结束。因此 $H$ 是无循环的。

现在令 $K$ 为 $H$ 的 D.N.。$H$ 在其运动的第 $K$ 段中做什么？它必须检验 $K$ 是否合格，给出“s”或“u”的判定。由于 $K$ 是 $H$ 的 D.N. 且 $H$ 是无循环的，判定不可能是“u”。另一方面，判定也不可能是“s”。因为如果是“s”，那么在运动的第 $K$ 段中，$H$ 必然要计算以 $K$ 为 D.N. 的机器所计算序列的前 $R(K-1)+1=R(K)$ 位数字，并把第 $R(K)$ 位写为由 $H$ 计算的序列的一位。前 $R(K)-1$ 位数字的计算会顺利完成，但计算第 $R(K)$ 位的指令将相当于“计算由 $H$ 计算机器的前 $R(K)$ 位，并写下第 $R(K)$ 位”。这个第 $R(K)$ 位数字将永远找不到。也就是说，$H$ 是循环的，这既与上一段的发现矛盾，也与判定“s”矛盾。因此两种判定都不可能，我们得出结论：不可能存在机器 $D$。

我们还可以进一步证明：不存在这样的机器 $E$——当给定任意机器 $M$ 的 S.D. 时，它能判定 $M$ 是否曾经打印某个给定符号（比如说 0）。

我们先证明：如果机器 $E$ 存在，那么就有一个一般过程来判定给定机器 $M$ 是否无限频繁地打印 0。设 $M_1$ 是一台打印与 $M$ 相同序列的机器，但在 $M$ 打印第一个 0 的位置上，$M_1$ 打印 0。$M_2$ 则把前两个 0 符号替换为 0，依此类推。因此，如果 $M$ 打印

```text
A B A 0 1 A A B 0 0 1 0 A B …
```

那么 $M_1$ 将打印

```text
A B A 0 1 A A B 0 0 1 0 A B …
```

而 $M_2$ 将打印

```text
A B A 0 1 A A B 0 0 1 0 A B … .
```

现在令 $F$ 为这样一台机器：当给定 $M$ 的 S.D. 时，它依次写下 $M$、$M_1$、$M_2$、… 的 S.D.（这样的机器是存在的）。我们把 $F$ 与 $E$ 组合，得到一台新机器 $G$。在 $G$ 的运动中，首先用 $F$ 写下 $M$ 的 S.D.，然后用 $E$ 检验它；若发现 $M$ 从不打印 0，就写下“:0:”；然后 $F$ 写下 $M_1$ 的 S.D. 并检验它；当且仅当 $M_1$ 从不打印 0 时打印“:0:”；依此类推。现在用 $E$ 检验 $G$。若发现 $G$ 从不打印 0，则 $M$ 无限频繁地打印 0；若 $G$ 有时打印 0，则 $M$ 并非无限频繁地打印 0。

类似地，存在一个一般过程来判定 $M$ 是否无限频繁地打印 1。把这些过程组合起来，我们就得到一个过程来判定 $M$ 是否打印无穷多个数字，也就是判定 $M$ 是否无循环。因此不可能存在机器 $E$。

本节中一直使用的短语“存在一个一般过程来判定……”与“存在一台机器来判定……”等价。只有当我们可以证明“可计算”的定义合理时，这种用法才是合理的。这些“一般过程”问题中的每一个，都可以表达为一个关于一般过程的问题：判定给定整数 $n$ 是否具有性质 $G(n)$（例如，$G(n)$ 可能表示“$n$ 合格”或“$n$ 是一个可证公式的哥德尔表示”）；而这等价于计算一个数，其第 $n$ 位数字在 $G(n)$ 为真时为 1，在 $G(n)$ 为假时为 0。

## 9. 可计算数的范围

我们尚未试图证明“可计算”数包括所有自然会被认为是可计算的数。所有能够给出的论证，从根本上说，都必然诉诸直觉；因此，在数学上相当不能令人满意。真正的问题是：“在计算一个数时，可以执行哪些可能的过程？”

我将使用的论证有三类：

1. 直接诉诸直觉。
2. 证明两个定义等价（当新定义具有更强直觉吸引力时）。
3. 给出大量可计算数的例子。

一旦承认可计算数都是“可计算的”，就可推出若干其他同一性质的命题。特别是，如果存在一个一般过程来判定希尔伯特函数演算中的公式是否可证，那么这种判定就可以由一台机器来完成。

**I. [类型 (a)]。** 这一论证只是第 1 节思想的展开。

计算通常通过在纸上写下某些符号来完成。我们可以假设这张纸像小学生的算术本一样划分成方格。在初等算术中，有时会用到纸的二维性质。但这种用法总是可以避免的；我想人们会同意，纸的二维性质并不是计算的本质。因此我假设计算是在一维纸上进行的，即在一张划分为方格的纸带上进行的。我还假设可以打印的符号数量是有限的。如果允许无穷多个符号，那么就会有相差任意小量的符号 [6]。限制符号数量的影响并不十分严重。我们总可以用符号序列来代替单个符号。因此，一个阿拉伯数字，如 17 或 999999999999999，通常被当作单个符号。类似地，在任何欧洲语言中，词都被当作单个符号（然而，汉语试图拥有可数无穷多个符号）。从我们的观点看，单个符号与复合符号的区别在于：复合符号如果太长，就无法一眼观察到。这与经验相符。我们无法一眼看出 9999999999999999 和 999999999999999 是否相同。

计算者在任一时刻的行为，由他正在观察的符号以及他当时的“心智状态”决定。我们可以假设，计算者一次能够观察的符号或方格数有一个界限 $B$。如果他想观察更多，就必须进行连续观察。我们还假设需要考虑的心智状态数是有限的。其理由与限制符号数量的理由性质相同。如果承认无穷多个心智状态，其中一些将是“任意接近”的并发生混淆。同样，这一限制并不会严重影响计算，因为更复杂的心智状态可以通过在纸带上写更多符号来避免。

让我们把计算者执行的操作分解为“简单操作”，这些操作足够基本，以至于难以想象它们还能再分。每一个这样的操作都包含由计算者和他的纸带构成的物理系统的某种变化。如果我们知道纸带上的符号序列、其中哪些正被计算者观察（可能带有特殊顺序）以及计算者的心智状态，我们就知道系统的状态。我们可以假设，在一次简单操作中被改变的符号不超过一个。任何其他变化都可以分解为这种简单变化。对于符号可能被这样改变的方格，其情形与所观察方格的情形相同。因此，不失一般性，我们可以假定符号被改变的方格总是“被观察的”方格。

除了这些符号变化之外，简单操作还必须包括观察方格分布的变化。新的观察方格必须能被计算者立即识别。我认为可以合理地假定：它们只能是与先前紧接观察过的方格中最近者距离不超过某个固定量的方格。设每个新的观察方格都在某个先前紧接观察过的方格的 $L$ 个方格之内。

关于“立即可识别性”，可能有人认为还有其他种类的方格是立即可识别的。特别是，带有特殊符号标记的方格可以被看作立即可识别的。现在，如果这些方格只用单个符号标记，那么它们只能有有限多个；把这些带标记的方格加入观察方格，不会扰乱我们的理论。另一方面，如果它们由符号序列标记，我们就不能把识别过程看作一个简单过程。这是一个基本点，应予说明。在大多数数学论文中，方程和定理都有编号。通常编号不超过（比如说）1000。因此，有可能通过定理编号一眼识别一个定理。但如果论文非常长，我们可能遇到定理 157767733443477；那么，在论文后面可能会发现“……因此（应用定理 157767733443477）我们有……”。为了确定相关定理是哪一个，我们必须逐位比较两个数字，可能还要用铅笔把各位划掉，以确保没有重复计数。尽管如此，如果仍然认为还有其他“立即可识别的”方格，只要这些方格能被我这种机器所能执行的某个过程找到，就不会扰乱我的主张。这个思想将在下面 III 中展开。

因此，简单操作必须包括：

a. 改变某个被观察方格上的符号。

b. 把某个被观察方格改变为距先前观察过的某个方格不超过 $L$ 个方格的另一个方格。

某些变化可能必然涉及心智状态的改变。因此，最一般的单一操作必须取为下列之一：

A. 符号的可能变化 (a)，连同心智状态的可能变化。

B. 观察方格的可能变化 (b)，连同心智状态的可能变化。

实际执行的操作，如第 250 页所提出的那样，由计算者的心智状态和观察到的符号决定。特别是，它们决定了操作执行后计算者的心智状态。

现在我们可以构造一台机器来完成这位计算者的工作。计算者的每个心智状态对应于机器的一个“m-构型”。机器扫描与计算者观察的 $B$ 个方格相对应的 $B$ 个方格。在任一步中，机器可以改变某个被扫描方格上的符号，或者把任何一个被扫描方格改为距其他某个被扫描方格不超过 $L$ 个方格的另一个方格。所执行的移动以及随后的构型，由被扫描符号和 m-构型决定。刚刚描述的机器与第 2 节定义的计算机器并无本质差别；对于任何这类机器，都可以构造一台计算机器来计算同一序列，即由计算者计算的序列。

**II. [类型 (b)]。**

如果希尔伯特函数演算 [7] 的记号被修改成系统的，并且只包含有限数量的符号，那么就可以构造一台自动 [8] 机器 $K$，它会找出该演算中所有可证公式 [9]。

现在令 $\alpha$ 为一个序列，并用 $G_\alpha(x)$ 表示命题“$\alpha$ 的第 $x$ 位数字是 1”，于是 [10] $\neg G_\alpha(x)$ 表示“$\alpha$ 的第 $x$ 位数字是 0”。进一步假设我们能找到一组刻画序列 $\alpha$ 的性质，它们可以用 $G_\alpha(x)$、表示“$x$ 是非负整数”的命题函数 $N(x)$ 以及表示“$y=x+1$”的 $F(x,y)$ 来表达。当把所有公式合取起来时，我们就得到一个公式，设为 $U$，它定义 $\alpha$。$U$ 的各项必须包括皮亚诺公理的必要部分，即

$$(\exists u)\,N(u)\ \&\ (x)\big(N(x)\to(\exists y)F(x,y)\big)\ \&\ \big(F(x,y)\to N(y)\big),$$

我们将其缩写为 $P$。

当我们说“$U$ 定义 $\alpha$”时，意思是：$\neg U$ 不是可证公式，并且对每个 $n$，下列公式 $(A_n)$ 或 $(B_n)$ 之一是可证的。

$$
\begin{aligned}
U\ \&\ F(n)&\to G_\alpha(u(n)), \qquad (A_n) \ [11]\\
U\ \&\ F(n)&\to \big(\neg G_\alpha(u(n))\big), \qquad (B_n)
\end{aligned}
$$

其中 $F(n)$ 表示 $F(u,u')\ \&\ F(u',u'')\ \&\ \ldots\ \&\ F(u^{(n-1)},u^{(n)})$。

我说，此时 $\alpha$ 是一个可计算序列：通过对 $K$ 作相当简单的修改，就可以得到计算 $\alpha$ 的机器 $K_\alpha$。

我们把 $K_\alpha$ 的运动分成若干段。第 $n$ 段专门用于寻找 $\alpha$ 的第 $n$ 位数字。第 $(n-1)$ 段结束后，在所有符号之后打印双冒号“::”，后续工作完全在双冒号右边的方格上进行。第一步是写字母 “A”，后接公式 $(A_n)$，然后写 “B”，后接 $(B_n)$。机器 $K_\alpha$ 随后开始做 $K$ 的工作，但每当找到一个可证公式时，就把它与 $(A_n)$ 和 $(B_n)$ 比较。若它与 $(A_n)$ 相同，则打印数字“1”，第 $n$ 段结束。若是 $(B_n)$，则打印“0”，该段结束。若两者都不同，则从中断处继续 $K$ 的工作。迟早会达到 $(A_n)$ 或 $(B_n)$ 之一；这由我们对 $\alpha$ 和 $U$ 的假设以及 $K$ 的已知性质推出。因此第 $n$ 段最终会结束；$K_\alpha$ 是无循环的；$\alpha$ 是可计算的。

还可以证明，以这种方式借助公理定义的数包括所有可计算数。这通过用函数演算描述计算机器来完成。

必须记住，我们赋予短语“$U$ 定义 $\alpha$”相当特殊的含义。可计算数并不包括所有（通常意义上的）可定义数。令 $\delta$ 为这样一个序列：其第 $n$ 位数字在 $n$ 合格时为 1，否则为 0。由第 8 节定理直接可知，$\delta$ 不可计算。就我们目前所知，可以计算出 $\delta$ 的任意指定若干位数字，但不能用一个统一的过程来做到。当已经算出足够多的 $\delta$ 的数字后，就需要本质上新的方法来获得更多数字。

**III.** 这可以看作对 I 的修改，或作为 II 的推论。

像 I 中一样，我们假设计算在纸带上进行；但我们避免引入“心智状态”，而是考虑一个更物理、更明确的对应物。计算者总是可以中断工作，离开并完全忘记它，之后再回来继续。如果他这样做，就必须留下一条指令说明（以某种标准形式写成），解释工作如何继续。这条指令说明就是“心智状态”的对应物。我们假设计算者以这种零碎方式工作，以至于他每次坐下只做一步。指令说明必须使他能够执行一步并写下下一步指令。因此，计算在任一阶段的进展状态完全由指令说明和纸带上的符号决定 [即系统的状态可以由单一表达式（符号序列）描述：纸带上的符号后接 $\Delta$（假设它不出现在别处），再后接指令说明。这个表达式可称为“状态公式”。] 我们知道，任一给定阶段的状态公式由上一步作出之前的状态公式决定，并且我们假定这两个公式之间的关系可以在函数演算中表达。换句话说，我们假设存在一条公理 $U$，它以任一阶段的状态公式与前一阶段状态公式之间的关系为术语，表达支配计算者行为的规则。若如此，我们就能构造一台机器来写下相继的状态公式，从而计算所需的数。

## 10. 大量可计算数的例子

先定义整变量的可计算函数和可计算变量等，会很有用。定义整变量的可计算函数有许多等价方式。最简单的或许如下。如果 $\gamma$ 是一个可计算序列，其中 0 出现无穷多次 [12]，且 $n$ 是整数，那么令 $\xi(\gamma,n)$ 为 $\gamma$ 中第 $n$ 个 0 与第 $(n+1)$ 个 0 之间的数字 1 的个数。于是，若对所有 $n$ 和某个 $\gamma$ 有 $\varphi(n)=\xi(\gamma,n)$，则 $\varphi(n)$ 是可计算的。一个等价定义如下。令 $H(x,y)$ 表示 $\varphi(x)=y$。如果我们能找到一条无矛盾的公理 $U_\varphi$，使得 $U_\varphi\to P$，并且对每个整数 $n$ 存在整数 $N$，使得

$$U_\varphi\ \&\ F(N)\ \to\ H(u(n),u(\varphi(n)))$$

并且若 $m\neq\varphi(n)$，则对某个 $N'$，

$$U_\varphi\ \&\ F(N')\ \to\ \big(\neg H(u(n),u(m))\big),$$

那么 $\varphi$ 可以称为可计算函数。

我们不能定义一般实变量的可计算函数，因为没有描述实数的一般方法；但我们可以定义可计算变量的可计算函数。若 $n$ 合格，令 $\gamma_n$ 为由 $M(n)$ 计算的数，并令

$$\alpha_n=\tan\big(\pi(\gamma_n-\tfrac12)\big),$$

除非 $\gamma_n=0$ 或 $\gamma_n=1$，这两种情况下 $\alpha_n=0$。于是，当 $n$ 遍历合格数时，$\alpha_n$ 遍历可计算数 [13]。现在令 $\varphi(n)$ 为一个可计算函数，并可证明它具有如下性质：对任何合格自变量，其值也是合格的 [14]。那么由 $f(\alpha_n)=\alpha_{\varphi(n)}$ 定义的函数 $f$ 是一个可计算函数，且可计算变量的所有可计算函数都能以此形式表达。

可给出多变量可计算函数、整变量的可计算值函数等的类似定义。

我将阐述若干关于可计算性的定理，但只证明 (ii) 和一个类似于 (iii) 的定理。

i. 可计算函数的可计算函数（整变量或可计算变量）是可计算的。

ii. 任何由可计算函数递归定义的整变量函数都是可计算的。即若 $\varphi(m,n)$ 可计算，$r$ 为某整数，则 $\eta(n)$ 可计算，其中

$$\eta(0)=r,\qquad \eta(n)=\varphi\big(n,\eta(n-1)\big).$$

iii. 若 $\varphi(m,n)$ 是二元整变量的可计算函数，则 $\varphi(n,n)$ 是 $n$ 的可计算函数。

iv. 若 $\varphi(n)$ 是值恒为 0 或 1 的可计算函数，则以 $\varphi(n)$ 为第 $n$ 位数字的序列是可计算的。

若把“实数”处处替换为“可计算数”，戴德金定理不能以通常形式成立。但它以下列形式成立：

v. 若 $G(\alpha)$ 是可计算数的命题函数，且

$$\text{a) }(\exists\alpha)(\exists\beta)\{G(\alpha)\ \&\ (\neg G(\beta))\},$$

$$\text{b) }G(\alpha)\ \&\ (\neg G(\beta))\ \to\ (\alpha<\beta),$$

并且存在一个一般过程来判定 $G(\alpha)$ 的真值，则存在一个可计算数 $\xi$，使得

$$G(\alpha)\ \to\ \alpha\leqslant\xi,\qquad \neg G(\alpha)\ \to\ \alpha\geqslant\xi.$$

换句话说，该定理对可计算数的任何部分成立，只要存在一个一般过程来判定给定数属于哪一类。

由于戴德金定理的这一限制，我们不能说一个可计算的有界递增可计算数列具有可计算极限。这可以通过考虑如下序列来理解：

$$-1,\ -\tfrac12,\ -\tfrac14,\ -\tfrac18,\ -\tfrac1{16},\ \tfrac12,\ \ldots .$$

另一方面，(v) 使我们能够证明：

1. 若 $\alpha$ 与 $\beta$ 可计算且 $\alpha<\beta$，并且 $\varphi(\alpha)<0<\varphi(\beta)$，其中 $\varphi(\alpha)$ 是可计算递增连续函数，则存在唯一可计算数 $\gamma$ 满足 $\alpha<\gamma<\beta$ 且 $\varphi(\gamma)=0$。

### 可计算收敛

若存在可计算变量 $\varepsilon$ 的可计算整值函数 $N(\varepsilon)$，使得我们可以证明：当 $\varepsilon>0$、$n>N(\varepsilon)$ 且 $m>N(\varepsilon)$ 时有 $|\beta_n-\beta_m|<\varepsilon$，则称可计算数列 $\beta_n$ **可计算收敛**。

于是我们可以证明：

i. 系数构成可计算数的可计算序列的幂级数，在其收敛区间内部的所有可计算点上可计算收敛。

ii. 可计算收敛数列的极限是可计算的。

有了“一致可计算收敛”的显然定义后：

i. 一致可计算收敛的可计算函数序列的极限是可计算函数。因此

ii. 系数构成可计算序列的幂级数之和，是其收敛区间内部的可计算函数。

由 (viii) 和 $\pi=4(1-\tfrac13+\tfrac15-\ldots)$ 我们推出 $\pi$ 可计算。

由 $e=1+1+\tfrac1{2!}+\tfrac1{3!}+\ldots$ 我们推出 $e$ 可计算。

由 (vi) 我们推出所有实代数数可计算。

由 (vi) 和 (x) 我们推出贝塞尔函数的实零点可计算。

### (ii) 的证明

令 $H(x,y)$ 表示“$\eta(x)=y$”，令 $K(x,y,z)$ 表示“$\varphi(x,y)=z$”。$U_\varphi$ 是 $\varphi(x,y)$ 的公理。我们取 $U_\eta$ 为

$$
\begin{aligned}
U_\eta :=&\ U_\varphi\ \&\ P\ \&\ (F(x,y)\to G(x,y))\\
&\ \&\ (G(x,y)\ \&\ G(y,z)\to G(x,z))\\
&\ \&\ (F(r)\to H(u,u(r)))\\
&\ \&\ (F(v,w)\ \&\ H(v,x)\ \&\ K(w,x,z)\to H(w,z))\\
&\ \&\ \big[H(w,z)\ \&\ (G(z,t)\lor G(t,z))\to(\neg H(w,t))\big].
\end{aligned}
$$

我不会给出 $U_\eta$ 的一致性证明。这样的证明可以用 Hilbert 与 Bernays 的 *Grundlagen der Mathematik*（Berlin, 1934）第 209 页及以下诸页所用的方法构造 [20]。从意义上说，一致性也是显然的。

假设对某个 $n,N$，我们已经证明

$$U_\eta\ \&\ F(N)\ \to\ H\big(u^{(n-1)},u(\eta(n-1))\big).$$

那么对某个 $M$，

$$U_\varphi\ \&\ F(M)\ \to\ K\big(u(n),u(\eta(n-1)),u(\eta(n))\big)$$

并且

$$
\begin{aligned}
U_\eta\ \&\ F(M)\ \to\ &F(u^{(n-1)},u^{(n)})\ \&\ H\big(u^{(n-1)},u(\eta(n-1))\big)\\
&\ \&\ K\big(u(n),u(\eta(n-1)),u(\eta(n))\big).
\end{aligned}
$$

又有

$$
\begin{aligned}
U_\eta\ \&\ F(M)\ \to\ &\big[F(u^{(n-1)},u^{(n)})\ \&\ H\big(u^{(n-1)},u(\eta(n-1))\big)\\
&\ \&\ K\big(u(n),u(\eta(n-1)),u(\eta(n))\big)\to H\big(u(n),u(\eta(n))\big)\big].
\end{aligned}
$$

因此

$$U_\eta\ \&\ F(M)\ \to\ H\big(u(n),u(\eta(n))\big).$$

还有

$$U_\eta\ \&\ F(r)\ \to\ H\big(u(0),u(\eta(0))\big).$$

因此对每个 $n$，某个形如

$$U_\eta\ \&\ F(M)\ \to\ H\big(u(n),u(\eta(n))\big)$$

的公式是可证的。还有，若 $M'\geqslant M$、$M'\geqslant m$ 且 $m\neq\eta(n)$，则

$$U_\eta\ \&\ F(M')\ \to\ G\big(u(\eta(n)),u(m)\big)\ \lor\ G\big(u(m),u(\eta(n))\big)$$

以及

$$
\begin{aligned}
U_\eta\ \&\ F(M')\ \to\ &\big[\{G(u(\eta(n)),u(m))\lor G(u(m),u(\eta(n)))\}\\
&\ \&\ H(u(n),u(\eta(n)))\ \to\ \neg H(u(n),u(m))\big].
\end{aligned}
$$

因此

$$U_\eta\ \&\ F(M')\ \to\ \neg H\big(u(n),u(m)\big).$$

于是我们第二个可计算函数定义中的条件得到满足。因此 $\eta$ 是可计算函数。

### (iii) 一个修改形式的证明

假设给定一台机器 $N$，它从这样一条纸带开始：纸带上在 F-方格上写有 ə ə，后接任意数量的字母 “F” 的序列，机器处于 m-构型 b；它会计算一个依赖于 “F” 的个数 $n$ 的序列 $\gamma_n$。若 $\varphi_n(m)$ 是 $\gamma_n$ 的第 $m$ 位数字，则以 $\varphi_n(n)$ 为第 $n$ 位数字的序列 $\beta$ 是可计算的。

我们假设 $N$ 的表已写成这样一种形式：每行在操作列中只出现一个操作。我们还假设 $\Xi$、$\Theta$、0 和 1 不在表中出现，并把 ə 全部替换为 $\Theta$，把 0 替换为 0，把 1 替换为 1。然后作进一步替换。任何形如

$$U\ \alpha\ P0\ B$$

的行，我们替换为

$$U\ \alpha\ P0\ re(B,u,h,k)$$

而任何形如

$$U\ \alpha\ P1\ B$$

的行，我们替换为

$$U\ \alpha\ P1\ re(B,v,h,k)$$

并向表中加入以下各行：

```text
u    pe(u₁,0)
u₁   R, Pk, R, PΘ, R, PΘ    u₂
u₂   re(u₃, u₃, k, h)
u₃   pe(u₂, F)
```

以及把 $u$ 换成 $v$、把 0 换成 1 的类似各行，再加入以下一行：

```text
c    R, PΞ, R, Ph           b
```

这样我们就得到计算 $\beta$ 的机器 $N'$ 的表。初始 m-构型是 c，初始被扫描符号是第二个 ə。

## 11. 对判定问题的应用

第 8 节的结果有一些重要应用。特别是，它们可以用来证明希尔伯特判定问题不可能有解。目前我只限于证明这一定理。关于该问题的表述，我必须请读者参阅 Hilbert 与 Ackermann 的 *Grundzüge der Theoretischen Logik*（Berlin, 1931）第 3 章 [21]。

因此，我打算证明：不存在一般过程来判定函数演算 $K$ 的一个给定公式 $U$ 是否可证；也就是说，不存在这样一台机器：给它这些公式中的任何一个 $U$，它最终会说出 $U$ 是否可证。

也许应当指出，我将证明的东西与哥德尔 [15] 的著名结果完全不同。哥德尔已经证明（在 *Principia Mathematica* 的形式体系中）存在这样的命题 $U$：$U$ 和 $\neg U$ 都不可证。由此可证：在该形式体系内，无法给出 *Principia Mathematica*（或 $K$）的一致性证明。另一方面，我将证明：不存在一般方法来判定给定公式 $U$ 在 $K$ 中是否可证，或者说，判定把 $\neg U$ 作为附加公理加入 $K$ 后所得的系统是否一致。

如果哥德尔所证明的结论的否定被证明了，即如果对每个 $U$，$U$ 或 $\neg U$ 是可证的，那么我们就会立即得到判定问题的解。因为我们可以发明一台机器 $K$，它连续地证明所有可证公式。迟早 $K$ 会达到 $U$ 或 $\neg U$。若达到 $U$，我们就知道 $U$ 可证。若达到 $\neg U$，则由于 $K$ 是一致的（Hilbert and Ackermann, p.65），我们知道 $U$ 不可证。

由于 $K$ 中没有整数，这些证明显得有些冗长。其基本思想却相当直截了当。

对每台计算机器 $M$，我们构造一个公式 $Un(M)$，并证明：如果存在一般方法来判定 $Un(M)$ 是否可证，那么就存在一般方法来判定 $M$ 是否曾经打印 0。

所涉及的命题函数的解释如下：

$RS_i(x,y)$ 解释为“在 $M$ 的完全构型 $x$ 中，方格 $y$ 上的符号是 $S_i$”。

$I(x,y)$ 解释为“在完全构型 $x$ 中，方格 $y$ 被扫描”。

$K_{q_m}(x)$ 解释为“在完全构型 $x$ 中，m-构型是 $q_m$”。

$F(x,y)$ 解释为“$y$ 是 $x$ 的直接后继”。

$Inst\{q_iS_jS_kLq_l\}$ 是下式的缩写：

$$
\begin{aligned}
(x,y,x',y') \to\ &(RS_j(x,y)\ \&\ I(x,y)\ \&\ K_{q_i}(x)\ \&\ F(x,x')\ \&\ F(y',y))\\
\to\ &(I(x',y')\ \&\ RS_k(x',y)\ \&\ K_{q_l}(x')\\
&\ \&\ (z)\big[F(y',z)\ \lor\ (RS_j(x',z)\to RS_k(x',z))\big]\big).
\end{aligned}
$$

$Inst\{q_iS_jS_kRq_l\}$ 和 $Inst\{q_iS_jS_kNq_l\}$ 应理解为以类似方式构造的其他表达式的缩写。

让我们把 $M$ 的描述放入第 6 节的第一标准形式。该描述由若干表达式组成，如“$q_i,S_j,S_k,Lq_l$”（或用 $R$ 或 $N$ 代替 $L$）。我们构成所有相应的表达式，如 $Inst\{q_iS_jS_kLq_l\}$，并取它们的逻辑和。我们称之为 $Des(M)$。

公式 $Un(M)$ 为

$$
\begin{aligned}
(\exists u)\big[&N(u)\ \&\ (x)\big(N(x)\to(\exists x')F(x,x')\big)\\
&\ \&\ (y,z)\big(F(y,z)\to N(y)\ \&\ N(z)\big)\ \&\ (y)RS_u(u,y)\\
&\ \&\ I(u,u)\ \&\ K_{q_1}(u)\ \&\ Des(M)\big]\\
&\to\ (\exists s)(\exists t)\big[N(s)\ \&\ N(t)\ \&\ RS_1(s,t)\big].
\end{aligned}
$$

$[N(u)\ \&\ \ldots\ \&\ Des(M)]$ 可缩写为 $A(M)$。

当我们代入第 259–260 页所提示的含义时，发现 $Un(M)$ 的解释是“在 $M$ 的某个完全构型中，$S_1$（即 0）出现在纸带上”。与此对应，我证明：

a) 如果在 $M$ 的某个完全构型中 $S_1$ 出现在纸带上，则 $Un(M)$ 可证。

b) 如果 $Un(M)$ 可证，则在 $M$ 的某个完全构型中 $S_1$ 出现在纸带上。

完成这一点后，定理的其余部分就是平凡的。

### 引理 1

如果在 $M$ 的某个完全构型中 $S_1$ 出现在纸带上，则 $Un(M)$ 可证。

我们必须说明如何证明 $Un(M)$。假设在第 $n$ 个完全构型中，纸带上的符号序列是 $S_{r(n,0)},S_{r(n,1)},\ldots,S_{r(n,n)},$ 其后除空白外别无他物；被扫描符号是第 $i(n)$ 个；m-构型是 $q_{k(n)}$。那么我们可以构成命题

$$
\begin{aligned}
&RS_{r(n,0)}(u^{(n)},u)\ \&\ RS_{r(n,1)}(u^{(n)},u')\ \&\ \ldots\ \&\ RS_{r(n,n)}(u^{(n)},u^{(n)})\\
&\ \&\ I\big(u^{(n)},u^{(i(n))}\big)\ \&\ K_{q_{k(n)}}(u^{(n)})\\
&\ \&\ (y)\big[F(y,u')\lor F(u,y)\lor F(u',y)\lor\ldots\lor F(u^{(n-1)},y)\lor RS_0(u^{(n)},y)\big],
\end{aligned}
$$

我们可将其缩写为 $CC_n$。

如前，$F(u,u')\ \&\ F(u',u'')\ \&\ \ldots\ \&\ F(u^{(r-1)},u^{(r)})$ 缩写为 $F(r)$。

我将证明所有形如 $A(M)\ \&\ F(n)\to CC_n$（缩写为 $CF_n$）的公式都是可证的。$CF_n$ 的含义是“$M$ 的第 $n$ 个完全构型如此这般”，其中“如此这般”代表 $M$ 实际上的第 $n$ 个完全构型。因此 $CF_n$ 应当可证，是可以预期的。

$CF_0$ 显然可证，因为在初始完全构型中，符号全为空白，m-构型是 $q_1$，被扫描方格是 $u$，即 $CC_0$ 为

$$(y)\,RS_0(u,y)\ \&\ I(u,u)\ \&\ K_{q_1}(u).$$

于是 $A(M)\to CC_0$ 是平凡的。

接下来我们证明对每个 $n$，$CF_n\to CF_{n+1}$ 可证。有三种情况要考虑：从 $n$ 到 $n+1$ 构型的移动中，机器向左移动、向右移动或保持不动。我们假设第一种情况成立，即机器向左移动。其他情况可用类似论证。若

$$r(n,i(n))=a,\quad r(n+1,i(n+1))=c,\quad k(i(n))=b,\quad k(i(n+1))=d,$$

则 $Des(M)$ 必须把 $Inst\{q_aS_bS_dLq_c\}$ 作为其一项，即

$$Des(M)\ \to\ Inst\{q_aS_bS_dLq_c\}.$$

因此

$$A(M)\ \&\ F(n+1)\ \to\ Inst\{q_aS_bS_dLq_c\}\ \&\ F(n+1).$$

但

$$Inst\{q_aS_bS_dLq_c\}\ \&\ F(n+1)\ \to\ (CC_n\to CC_{n+1})$$

是可证的，所以

$$A(M)\ \&\ F(n+1)\ \to\ (CC_n\to CC_{n+1})$$

以及

$$(A(M)\ \&\ F(n)\to CC_n)\ \to\ (A(M)\ \&\ F(n+1)\to CC_{n+1})$$

即 $CF_n\to CF_{n+1}$ 也是可证的。

于是 $CF_n$ 对每个 $n$ 可证。现在，本引理的假设是：在 $M$ 打印的符号序列中，某个完全构型的某处出现 $S_1$；也就是说，对某些整数 $N,K$，$CC_N$ 把 $RS_1(u(N),u(K))$ 作为其一项，因此 $CC_N\to RS_1(u(N),u(K))$ 可证。我们有

$$CC_N\ \&\ \to\ RS_1(u(N),u(K))$$

以及

$$A(M)\ \&\ F(N)\ \to\ CC_N.$$

我们还有

$$(\exists u)A(M)\ \to\ (\exists u)(\exists u')\ldots(\exists u^{(N')})\,A(M)\ \&\ F(N),$$

其中 $N'=\max(N,K)$。

$$(\exists u)A(M)\ \to\ \exists u(\exists u')\ldots(\exists u^{(N')})\,RS_1(u(N),u(K)),$$

$$(\exists u)A(M)\ \to\ (\exists u)(\exists u^{(N)})(\exists u^{(K)})\,RS_1(u(N),u(K)),$$

$$(\exists u)A(M)\ \to\ (\exists s)(\exists t)\,RS_1(s,t),$$

即 $Un(M)$ 可证。

引理 1 证明完毕。

### 引理 2

如果 $Un(M)$ 可证，则在 $M$ 的某个完全构型中 $S_1$ 出现在纸带上。

如果我们把任意命题函数代入一个可证公式中的函数变元，就得到一个真命题。特别是，若把第 259–260 页所列表述的含义代入 $Un(M)$，我们就得到一个真命题，其含义是“在 $M$ 的某个完全构型的纸带上某处出现 $S_1$”。

现在我们可以说明判定问题不可能被解决。假设相反。那么就存在一个一般（机械）过程来判定 $Un(M)$ 是否可证。由引理 1 和 2，这意味着存在一个过程来判定 $M$ 是否曾经打印 0，而由第 8 节，这是不可能的。因此判定问题不可能被解决。

鉴于对量词系统受限的公式已有大量判定问题的特殊情形解，把 $Un(M)$ 表达成所有量词都在开头的格式是很有趣的。$Un(M)$ 事实上可以表达为形式

$$(u)(\exists x)(w)(\exists u_1)\ldots(\exists u_n)\,B, \qquad (I)$$

其中 $B$ 不含量词，且 $n=6$。通过不重要的修改，我们可以得到一个具有 $Un(M)$ 所有本质性质的公式，其为形式 (I) 且 $n=5$。

## 附录：可计算性与有效可计算性

下面概述证明：所有有效可计算（即 $\lambda$-可定义）序列都是可计算的，反之亦然。这里假定读者理解丘奇与克利尼所使用的“良构公式”（W.F.F.）和“转换”等术语。在第二个证明中，若干公式的存在性未经证明而被假定；这些公式可以借助例如 Kleene 的论文 “A theory of positive integers in formal logic”, *American Journal of Math.*, 57 (1935), 153–173, 219–244 的结果直接构造出来。

表示整数 $n$ 的 W.F.F. 记为 $N_n$。若序列 $\gamma$ 的第 $n$ 位数字为 $\varphi_\gamma(n)$，并且 $1+\varphi_\gamma(n)$ 是 $n$ 的 $\lambda$-可定义函数，即存在 W.F.F. $M_\gamma$ 使得对所有整数 $n$，

$$\{M_\gamma\}(N_n)\ \operatorname{conv}\ N_{\varphi_\gamma(n)+1},$$

则称 $\gamma$ 是 $\lambda$-可定义的或有效可计算的；也就是说，根据 $\gamma$ 的第 $n$ 位数字是 1 还是 0，$\{M_\gamma\}(N_n)$ 可转换为 $\lambda xy.x(x(y))$ 或 $\lambda xy.x(y)$。

为证明每个 $\lambda$-可定义序列 $\gamma$ 都是可计算的，我们必须说明如何构造一台机器来计算 $\gamma$。为便于机器使用，我们对转换演算作一个平凡修改：用 $x,x',x'',\ldots$ 作为变元，而不是 $a,b,c,\ldots$。现在构造一台机器 $L$，当给定公式 $M_\gamma$ 时，它写下序列 $\gamma$。$L$ 的构造在某种程度上类似于证明函数演算中所有可证公式的机器 $K$ 的构造。我们先构造一台选择机 $L_1$：若给定一个 W.F.F.（设为 $M$）并作适当操纵，它能得到 $M$ 可转换成的任何公式。然后可以把 $L_1$ 修改成一台自动机 $L_2$，它依次得到 $M$ 可转换成的全部公式（参见第 252 页脚注）。机器 $L$ 把 $L_2$ 作为一部分包含在内。当给定公式 $M_\gamma$ 时，$L$ 的运动分为若干段，其中第 $n$ 段致力于寻找 $\gamma$ 的第 $n$ 位数字。该段的第一个阶段是形成 $\{M_\gamma\}(N_n)$。然后把此公式交给机器 $L_2$，它把它相继转换成各种其他公式。每一个可转换成的公式最终都会出现；每找到一个，就把它与

$$\lambda x[\lambda x'[\{x\}(\{x\}(x'))]],\quad\text{即 }N_2,$$

以及

$$\lambda x[\lambda x'[\{x\}(x')]],\quad\text{即 }N_1$$

比较。若与第一个相同，则机器打印数字 1，第 $n$ 段结束。若与第二个相同，则打印 0，该段结束。若两者都不同，则恢复 $L_2$ 的工作。由假设，$\{M_\gamma\}(N_n)$ 可转换为 $N_2$ 或 $N_1$ 之一；因此第 $n$ 段最终会结束，即 $\gamma$ 的第 $n$ 位数字最终会被写下。

为证明每个可计算序列 $\gamma$ 都是 $\lambda$-可定义的，我们必须说明如何找到一个公式 $M_\gamma$，使得对所有整数 $n$，

$$\{M_\gamma\}(N_n)\ \operatorname{conv}\ N_{1+\varphi_\gamma(n)}.$$

设 $M$ 是计算 $\gamma$ 的机器，并对 $M$ 的完全构型取某种数字描述，例如取第 6 节所述的完全构型的 D.N.。令 $\xi(n)$ 为 $M$ 的第 $n$ 个完全构型的 D.N.。机器 $M$ 的表给我们一个 $\xi(n+1)$ 与 $\xi(n)$ 之间的关系：

$$\xi(n+1)=p_\gamma(\xi(n)),$$

其中 $p_\gamma$ 是一个形式非常受限（尽管通常并不很简单）的函数：它由 $M$ 的表决定；$p_\gamma$ 是 $\lambda$-可定义的（我省略证明），即存在 W.F.F. $A_\gamma$，使得对所有整数 $n$，

$$\{A_\gamma\}(N_{\xi(n)})\ \operatorname{conv}\ N_{\xi(n+1)}.$$

令 $U_\gamma$ 表示

$$\lambda u[\{\{u\}(A_\gamma)\}(N_r)],$$

其中 $r=\xi(0)$；则对所有整数 $n$，

$$\{U_\gamma\}(N_n)\ \operatorname{conv}\ N_{\xi(n)}.$$

可以证明存在一个公式 $V$，使得

$$
\{\{V\}(N_{\xi(n+1)})\}(N_{\xi(n)})\ 
\begin{cases}
\operatorname{conv} N_1, & \text{若从第 }n\text{ 个到第 }(n+1)\text{ 个完全构型打印了数字 0；}\\
\operatorname{conv} N_2, & \text{若打印了数字 1；}\\
\operatorname{conv} N_3, & \text{否则。}
\end{cases}
$$

令 $W_\gamma$ 表示

$$\lambda u[\{\{V\}(\{A_\gamma\}(\{U_\gamma\}(u)))\}(\{U_\gamma\}(u))],$$

于是对每个整数 $n$，

$$\{\{V\}(N_{\xi(n+1)})\}(N_{\xi(n)})\ \operatorname{conv}\ \{W_\gamma\}(N_n).$$

再令 $Q$ 为一个公式，使得

$$\{\{Q\}(W_\gamma)\}(N_s)\ \operatorname{conv}\ N_{r(s)},$$

其中 $r(s)$ 是使 $(W_\gamma)(N_q)$ 可转换为 $N_1$ 或 $N_2$ 的第 $s$ 个整数 $q$。那么，若 $M_\gamma$ 表示

$$\lambda w[\{W_\gamma\}(\{\{Q\}(W_\gamma)\}(w))],$$

它将具有所要求的性质。[16]

## 1937 年修正

**论可计算数及其在判定问题中的应用——一项修正**

**A. M. 图灵**

在题为 *On computable numbers, with an application to the Entscheidungsproblem* [17] 的论文中，作者给出了“狭义函数演算”判定问题不可解性的证明 [18]。该证明包含若干形式错误，这里予以修正；同一论文中还有一些陈述也应修改，尽管它们按原样并非实际错误。

所引论文第 260 页上关于 $Inst\{q_iS_jLq_l\}$ 的表达式应改为

$$
\begin{aligned}
(x,y,x',y')\ \to\ \{&(RS_j(x,y)\ \&\ I(x,y)\ \&\ K_{q_l}(x)\ \&\ F(x,x')\ \&\ F(y',y))\\
\to\ &(I(x',y')\ \&\ RS_k(x',y)\ \&\ K_{q_i}(x')\ \&\ (z)\big[F(y',z)\\
&\ \lor\ \big((RS_0(x,z))\to (RS_1(x,y))\to RS_0(x',z)\big)\ \&\ \ldots\\
&\ \ \&\ \big((RS_0(x,z))\to RS_M(x',z)\big)\big]\big)\},
\end{aligned}
$$

其中 $S_0,S_1,\ldots,S_M$ 是 $M$ 能打印的符号。

所引论文第 261 页第 33 行的陈述，即

> “$Inst\{q_aS_bS_dLq_c\}\ \&\ F(n+1)\to(CC_n\to CC_{n+1})$ 是可证的”

是错误的（即使采用 $Inst\{q_aS_bS_dLq_c\}$ 的新表达式也是如此）：例如，我们无法推出 $F(n+1)\to(\neg F(u,u''))$，因此永远不能使用 $Inst\{q_aS_bS_dLq_c\}$ 中的项

$$F(y',z)\ \lor\ \big[(RS_0(x,z)\to RS_0(x',z))\ \&\ \ldots\ \&\ (RS_0(x,z)\to RS_M(x',z))\big].$$

为纠正这一点，我们引入一个新的函数变元 $G$（$G(x,y)$ 解释为“$x$ 在 $y$ 之前”）。于是，若 $Q$ 是下式的缩写：

$$
\begin{aligned}
(x)\exists w(y,z)\{&F(x,w)\ \&\ (F(x,y)\to G(x,y))\\
&\lor\ (F(x,y)\ \&\ G(z,y)\to G(x,y))\\
&\ \&\ [G(z,x)\lor (G(x,y)\ \&\ F(y,z))\lor (F(x,y)\ \&\ F(z,y))\to(\neg F(x,z))]\},
\end{aligned}
$$

则修正后的公式 $Un(M)$ 为

$$(\exists u)A(M)\ \to\ (\exists s)(\exists t)RS_1(s,t),$$

其中 $A(M)$ 是下式的缩写：

$$Q\ \&\ (y)RS_0(u,y)\ \&\ I(u,u)\ \&\ K_{q_1}(u)\ \&\ Des(M).$$

于是第 261 页（第 33 行）的陈述应改为

$$Inst\{q_aS_bS_dLq_c\}\ \&\ Q\ \&\ F(n+1)\ \to\ (CC_n\to CC_{n+1})$$

而第 29 行应改为

$$r(n,i(n))=b,\quad r(n+1,i(n))=d,\quad k(n)=a,\quad k(n+1)=c.$$

第 260 页第 15 行中的“逻辑和”应改为“合取”。有了这些修改，证明就是正确的。$Un(M)$ 可置于第 263 页的形式 (I)，其中 $n=4$。

由于“可计算数”定义方式（第 233 页）的特殊性，会出现某种困难。如果可计算数要满足直觉要求，我们应当有：

> 如果我们能给出一条规则，使每个正整数 $n$ 与两个有理数 $a_n,b_n$ 相关联，并满足 $a_n\leqslant a_{n+1}<b_{n+1}\leqslant b_n$，$b_n-a_n<2^{-n}$，那么就存在可计算数 $\alpha$，使得对每个 $n$ 有 $a_n\leqslant\alpha\leqslant b_n$。  (A)

这可以给出一个按通常数学标准有效的证明，但该证明用到了排中律。另一方面，以下陈述是假的：

> 存在这样一条规则：给定 (A) 中序列 $a_n,b_n$ 的形成规则，我们就能得到一台计算机器计算 $\alpha$ 的 D.N.。  (B)

至少如果我们采用约定：形如 $m/2^n$ 的数的小数总是以零结尾，那么 (B) 为假，可如下看出。令 $N$ 为某台机器，并如下定义 $c_n$：若在到达第 $n$ 个完全构型时 $N$ 尚未打印数字 0，则 $c_n=\tfrac12$；若 0 第一次作为第 $m$ 个完全构型被打印（$m\leqslant n$），则 $c_n=\tfrac12-2^{m-3}$。令 $a_n=c_n-2^{-n-2}$，$b_n=c_n+2^{-n-2}$。则 (A) 的不等式成立，并且若 $N$ 曾经打印 0，$\alpha$ 的第一位数字为 0，否则为 1。如果 (B) 为真，我们就有了一种方法：给定 $N$ 的 D.N. 后求出 $\alpha$ 的第一位数字；也就是说，我们将能判定 $N$ 是否曾经打印 0，这与所引论文第 8 节的结果矛盾。因此，尽管 (A) 表明必定存在例如计算欧拉常数的机器，但我们目前无法描述任何这样的机器，因为我们还不知道欧拉常数是否形如 $m/2^n$。

这种令人不快的局面可以通过修改可计算数与可计算序列相关联的方式来避免，而可计算数的总体保持不变。有许多方法可以做到 [19]，这里给出一个例子。假设可计算序列 $\gamma$ 的第一位数字是 $i$，其后是重复 $n$ 次的 1，再后是 0，最后是第 $r$ 位数字为 $c_r$ 的序列；那么序列 $\gamma$ 应对应于实数

$$(2i-1)n+\sum_{r=1}^{\infty}(2c_r-1)\left(\frac23\right)^r.$$

如果把计算 $\gamma$ 的机器也看作计算这个实数，那么 (B) 成立。用数字序列表示实数的唯一性现在丧失了，但这在理论上无关紧要，因为 D.N. 在任何情况下都不是唯一的。
